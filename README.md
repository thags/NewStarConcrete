# New Star Concrete Pumping

A four-page static site for New Star Concrete Pumping. It runs directly on GitHub Pages without a build process. Pages are in `index.html`, `concrete-pumping/`, `gallery/`, and `contact-us/`. Photos and the favicon are in `assets/`.

## Contact form setup

Edit only `site-config.js` to choose the receiving mailbox:

```js
window.siteConfig = {
  contactEmail: "you@example.com"
};
```

The email address starts blank. With no valid address set, the site hides its form and email links and displays the phone number instead. Once set, the contact form posts to FormSubmit and the same address appears in the footer and contact information. No account or server is needed, but the mailbox owner must confirm the activation email generated by the first submission. Repeat the confirmation if you change the recipient. FormSubmit's default confirmation page appears after a successful submission. A local preview cannot verify delivery; test the published page with a real submission.

## Local preview

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000/`.

## GitHub Pages

1. Push updates to the repository's default branch. GitHub Pages publishes from `/ (root)` on that branch.
2. Visit the Pages URL listed under **Settings → Pages** after publishing finishes. Links and asset paths are relative, so the site works at a project URL.
3. Add a real address in `site-config.js` when ready, push the change, submit a test inquiry, and confirm the activation email in that mailbox.

If you later connect the existing domain, configure it in the repository's Pages settings and update DNS as instructed by GitHub. The repo does not include a `CNAME` file while it uses the project URL.
